# micro-pi 学习版本归档

这里按 PRD 的版本路线保存每个阶段的代码快照，方便后续回看、对比和整理课程。

## 使用约定

- 每个子目录对应一个独立版本。
- 完成一个版本后，把该版本的完整可运行代码复制到对应目录。
- 不在旧版本目录中继续修改；新能力放到下一个版本目录。
- `src/` 保持为当前正在开发的最新代码。
