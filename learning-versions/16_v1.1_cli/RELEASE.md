# micro-pi v1.1.0

本次结课版本把 learn-pi 教程构建出的 Agent 安装为 `micro-pi` 终端命令。

1. 使用 Python 3.12 环境，从本页附件下载 `learn_pi-1.1.0-py3-none-any.whl`。
2. 运行 `python -m pip install learn_pi-1.1.0-py3-none-any.whl`。
3. 在练习目录运行 `micro-pi`，按照向导配置模型后，请它用 `word_count` 统计 `one two three four`。

`SHA256SUMS.txt` 提供 wheel 的 SHA-256。完整步骤见 [V1.1 教程](https://github.com/tutu-zzz/learn-pi/tree/v1.1.0/learning-versions/16_v1.1_cli#readme)。
