# micro-pi v1.1.1

可安装版本的源码和构建配置现位于仓库根目录的 `cli/`。学习路线仍从 V0.1 到 V1.0。

1. 使用 Python 3.12 环境，从本页附件下载 `learn_pi-1.1.1-py3-none-any.whl`。
2. 运行 `python -m pip install learn_pi-1.1.1-py3-none-any.whl`。
3. 在练习目录运行 `micro-pi`，按照向导配置模型后，请它用 `word_count` 统计 `one two three four`。

`SHA256SUMS.txt` 提供 wheel 的 SHA-256。完整步骤见 [CLI 安装与使用](https://github.com/tutu-zzz/learn-pi/tree/v1.1.1/cli#readme)。
